⚑ IssueFlow

Ticket management backend — Spring Boot 3.4.12 on Java 21.

About

IssueFlow is a stateless REST backend for managing projects, tickets, comments, dependencies and attachments. Tickets follow a forward-only state machine (TODO → IN_PROGRESS → IN_REVIEW → DONE) with soft deletes, optimistic locking and auto-assignment to the least-loaded developer. A scheduled job escalates overdue tickets.

AuthStateless JWT (HS256) issued by /auth/login.
ObservabilityOTLP traces → Jaeger; Micrometer metrics → Prometheus.
PersistencePostgreSQL 16, Flyway migrations, JPA & Hibernate.
AuditAppend-only log of state changes per entity.

API documentation

Swagger UI /swagger-ui.html Interactive API explorer. Use Authorize with a JWT from POST /auth/login. OpenAPI JSON /v3/api-docs Machine-readable contract (OpenAPI 3.0). Also available statically at openapi.yaml in the repo.

Operations & observability

  • /actuator/healthAggregate health (liveness + readiness with DB probe).
  • /actuator/infoBuild / application metadata.
  • /actuator/metricsIndex of metric names exposed by Micrometer.
  • /actuator/prometheusScrape endpoint for Prometheus (JVM, HTTP, Hikari, custom).
